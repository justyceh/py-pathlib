# Python Pathlib Tutorial

```
- The main.py file defines two functions, one for listing subdirectories, one for organizing your downloads folder

- To use the downloads organizer run

python3 main.py

- Make sure to replace the username variable to change the User to be your computers user or change the path to point to your downloads folder


```

- This file uses the Path object so it can work on unix or windows systems

- It checks for different file types and sorts them into according folders based on the extension, img extensions, video extensions, spreadsheet extensions, etc

- Everything is contained within the organizeDownloads()

- Multiple variables are named with the suffix extensions, you can add strings onto here for different image types and spreadsheet types, or video types so that the program is able to sort them
